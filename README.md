# MEC Landing Page

Premium dark-luxury landing page for MEC built with:

- Next.js App Router
- Tailwind CSS
- Framer Motion
- React Three Fiber
- Minimal Sanity CMS foundation

## Run

```bash
npm install
npm run dev
```

## Notes

- Reference images are copied to `public/images/`.
- Sanity env vars live in `.env.example`.
- The page is optimized for Vercel deployment and responsive rendering.
